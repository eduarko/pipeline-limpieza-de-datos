# Pipeline de limpieza de datos

Pipeline escrito en python utilizando pandas para la limpieza y preparación de datos para posteriormente alimentar un dashboard en power bi


#Objetivo

Reducir el trabajo manual en la limpieza y transformación de datos, con la finalidad de obtener mas tiempo para actualizar el dashboard y realizar el análisis de los datos

#Stack tecnologico utilizado

-**Python 3.13** - lenguaje del código

-**pandas** - manipulación y limpieza de datos

-**python-dotenv** - gestión de variables de entorno
